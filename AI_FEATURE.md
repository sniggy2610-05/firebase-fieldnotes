# AI Usage Documentation

## Purpose

AI was used as a development support tool while completing the Firebase Fieldnotes assignment. It helped me understand the Firebase setup process and organize the testing evidence required for the assignment.

## How AI Was Used

I used ChatGPT for the following purposes:

1. **Firebase Setup Guidance:** I used AI guidance to understand how to create a Firebase project, configure Cloud Firestore, connect Firebase to my Flutter application, and complete the Firebase initialization process.

2. **Testing and Screenshot Guidance:** I used AI to understand the testing requirements (T1–T8), identify what functionality needed to be tested, and determine which screenshots to capture as evidence for the assignment.

## Implementation and User Control

The application was tested and run locally in Flutter. I reviewed the Firebase configuration, performed the required tests, and captured the screenshots myself.

AI assistance was used as a development reference. The application does not contain an AI-powered chatbot, prediction system, or recommendation feature.

## Limitations

AI guidance does not guarantee that an implementation is correct. I verified the application by running it, testing its functionality, checking Firestore data, and using the Firestore Rules Playground.

## Conclusion

AI helped me navigate Firebase configuration and understand the assignment's testing and documentation requirements. The final application functionality and testing results were verified through my own development and testing process.
